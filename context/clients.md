## ลูกค้าหลัก (ICP)

- อายุ: 22–32 (แกนกลาง 25–28)
- อาชีพ / ไลฟ์สไตล์: เพิ่งเริ่มทำงาน–ทำงาน 3–6 ปี · agency, tech, ครีเอทีฟ, ฟรีแลนซ์
  เลิกงาน 18:00–19:00 · เสพ IG/TikTok เป็นหลัก · จ่ายค่าประสบการณ์มากกว่าค่าของ
- รายได้ประมาณ: 30,000–70,000 บาท/เดือน
- อยู่แถวไหน: ทองหล่อ–เอกมัย–พระโขนง / สาทร–นราธิวาส–พระราม 3
- สัดส่วนที่เราโฟกัส: ผู้หญิง ~65% · LGBTQ+ ~25%

## เขาอยากได้อะไรจริงๆ (ไม่ใช่แค่ตัวสินค้า)

- อยากมี "ที่ของตัวเอง" หลังเลิกงาน ที่ไม่ใช่บาร์และไม่ใช่ห้องนอน
- อยากได้เพื่อนใหม่ที่ไม่ใช่เพื่อนร่วมงาน — โดยไม่ต้องฝืนตัวเองไปงาน networking
- อยากรู้สึกว่าร่างกาย "รีเซ็ต" ได้จริงในเวลา 60–75 นาที เพราะมีเวลาแค่นั้น
- อยากมีรูป/สตอรี่ที่ดูมีชีวิตชีวาลง IG แบบไม่ต้องจัดฉาก

## Pain / สิ่งที่ทำให้เขาหงุดหงิดอยู่ทุกวันนี้

- ยิมเงียบและเหงา ไม่มีใครทัก ไปคนเดียวแล้วเบื่อ เลิกไปในเดือนที่สอง
- สปา/ice bath ที่มีอยู่โทน "ผู้ใหญ่" มาก เข้าไปแล้วรู้สึกแก่ขึ้น 10 ปี
- ค่าสมาชิกรายปีแพงและผูกยาว จ่ายแล้วไม่ได้ใช้
- จองยาก ต้องแชท LINE รอตอบ ไม่รู้ว่ารอบไหนว่าง
- ไปที่ใหม่คนเดียวแล้วกลัวเป็นคนแปลกหน้าในกลุ่มที่เขาสนิทกันอยู่แล้ว
- (สำหรับผู้หญิง/LGBTQ+) กังวลเรื่องสายตาและความปลอดภัยตอนอยู่ในชุดว่ายน้ำ

## Objections — เหตุผลที่เขาลังเลไม่ซื้อ + เราตอบว่าอะไร

| ข้อลังเล | เราตอบว่า |
|---|---|
| "แช่น้ำเย็นน่ากลัว ทนไม่ได้หรอก" | รอบแรกมี host ยืนข้างอ่างนับให้ เริ่มที่ 60 วินาที ขึ้นได้ตลอดเวลา 92% ของสมาชิกใหม่ผ่านรอบแรกได้ |
| "ไปคนเดียว จะเข้ากับคนอื่นได้เหรอ" | ทุกรอบมี host แนะนำให้รู้จักกัน และ 7 ใน 10 คนในรอบก็มาคนเดียวเหมือนกัน |
| "แพงไปไหม" | Social Trial 390 บาท ลองได้ทั้ง Grounding และ Moving ก่อนตัดสินใจ ไม่ต้องสมัครสมาชิก |
| "ผูกสัญญายาวหรือเปล่า" | ไม่มีสัญญา รายเดือนยกเลิกได้ทุกเมื่อ ไม่มีค่าปรับ |
| "ไม่เคยออกกำลังกาย จะตามไม่ทัน" | คลาสเต้นและ hyrox มีระดับ Easy ทุกวัน · โค้ชปรับท่าให้รายคน |
| "ไม่มีเวลา" | รอบละ 60–75 นาที มีรอบ 07:00 / 12:15 / 18:00 / 19:30 · จองล่วงหน้าแค่ 2 ชั่วโมงก็ได้ |
| "กลัวไม่ปลอดภัย / ไม่สบายใจ" | มี women & queer-only rounds ทุกวัน · locker แยก · code of conduct + host ประจำรอบทุกครั้ง |

## เขาเปรียบเทียบเรากับอะไร

- ยิมรายเดือนใกล้คอนโด (ถูกกว่า แต่เหงาและไม่มี recovery)
- studio ice bath / sauna เฉพาะทาง (ดีแต่แพงต่อครั้ง และโทนผู้ใหญ่)
- คลาสเต้น/พิลาทิสรายครั้ง (สนุกแต่ไม่มี recovery และไม่มี community ต่อเนื่อง)
- **"ไม่ทำอะไรเลย"** — นอนดูซีรีส์ที่บ้าน (คู่แข่งตัวจริงที่ใหญ่ที่สุด)

## Trigger — อะไรทำให้เขาตัดสินใจวันนี้

- เพื่อนชวน / เห็นสตอรี่เพื่อนไป Social Night
- เพิ่งจบสัปดาห์ที่นอนไม่หลับ เครียดงานหนัก อยากรีเซ็ต
- ต้นเดือน / ตั้งใจใหม่ (เงินเดือนเพิ่งออก)
- ย้ายคอนโดมาแถวนี้ ยังไม่รู้จักใคร
- เห็นโปร Social Trial 390 บาท แล้วรู้สึกว่า "ลองแล้วไม่เจ็บ"
