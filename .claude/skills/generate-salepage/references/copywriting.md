# Copywriting — Thai Salepage

อ่านไฟล์นี้ตอน Stop 3 · ทุกบรรทัดต้องผ่านกฎใน `context/voice.md` ก่อน

---

## หลักการ 5 ข้อ

1. **ชัดชนะเท่ ** — คนอ่านไม่ได้มาชื่นชมความคมคำ เขามาหาว่า "อันนี้ช่วยฉันได้ไหม"
2. **Benefit นำ Feature ตาม** — "หลับลึกคืนนั้น" (benefit) แล้วค่อย "ice bath 3–11°C" (feature)
3. **เจาะจงชนะกว้าง** — "รอบละไม่เกิน 10 คน" ชนะ "รอบเล็กๆ อบอุ่น" ทุกครั้ง
   ตัวเลข ชื่อ เวลา ราคา ระยะทาง = ความน่าเชื่อถือ
4. **ใช้ภาษาลูกค้า ไม่ใช่ภาษาบริษัท** — ดึงคำจริงจาก `clients.md` (pain, objection) มาใช้ตรงๆ
5. **หนึ่ง section หนึ่งความคิด** — ถ้า section ต้องอธิบาย 2 เรื่อง ให้แยกเป็น 2 section

## Hero — 5 วินาทีต้องตอบให้ครบ

| ต้องตอบ | อยู่ที่ไหน |
|---|---|
| นี่คืออะไร | headline |
| ฉันได้อะไร / เพื่อใคร | sub-headline |
| ต้องทำอะไรต่อ | ปุ่ม CTA |
| เชื่อได้ไหม | micro-trust ใต้ปุ่ม (ดาว, จำนวนสมาชิก, "รอบละ 10 คน") |

**สูตร headline ที่ใช้ได้จริง** (เลือก 1 แล้วเขียน 3 เวอร์ชันให้ user เลือก):
- ผลลัพธ์ + กรอบเวลา → "หลับลึกคืนนี้ ได้เพื่อนใหม่คืนเดียวกัน"
- ปฏิเสธทางเลือกเดิม → "ยิมที่ไม่มีใครทักคุณ ไม่ใช่ที่นี่"
- เจาะจงกลุ่ม + ผลลัพธ์ → "ที่รีเซ็ตของคนวัยทำงานย่านทองหล่อ ที่มาคนเดียวก็ไม่เหงา"
- ถามคำถามที่เขาตอบ "ใช่" → "เคยจ่ายค่าสมาชิกยิมแล้วไม่ได้ไปไหม"

❌ ห้าม: "ยินดีต้อนรับสู่…" · "เราคือผู้นำด้าน…" · "เปลี่ยนชีวิตคุณไปตลอดกาล"

## โครง section + งานของ copy

| Section | งานเดียวของมัน | เทคนิค |
|---|---|---|
| Hero | หยุดคน + บอกว่าได้อะไร | สูตรด้านบน |
| Social proof bar | ทำให้เชื่อใน 2 วินาที | ตัวเลขจริง 3–4 ตัว ไม่ใส่คำโฆษณา |
| Problem | ให้เขารู้สึก "นี่กูเลย" | ใช้คำที่เขาพูดเอง 3–4 bullet · อย่าเทศนา |
| Solution / USP | เราต่างจากทางเลือกอื่นยังไง | เทียบตรงๆ กับ "ทางเลือกอื่น" ไม่ต้องด่าคู่แข่ง |
| Services | เห็นภาพว่าไปทำอะไร | ชื่อ + ได้ผลอะไร + ใช้เวลาเท่าไหร่ |
| How it works | ลดความกลัวของครั้งแรก | 3–4 ขั้น เริ่มจาก "จองออนไลน์" จบที่ "วันนั้นมาถึงแล้วเจออะไร" |
| Pricing | ทำให้การจ่ายรู้สึกคุ้ม | value anchor + highlight hero offer + guarantee ใต้ปุ่ม |
| Testimonials | proof จากคนที่เหมือนเขา | ชื่อ + อาชีพ + **ผลลัพธ์ที่วัดได้** + รูปจริง |
| FAQ | ปิด objection ที่ค้าง | 5 ข้อจาก `clients.md` · ตอบตรง ไม่แก้ตัว |
| Lead form | ให้เขากรอกจนจบ | ดู `lead-form.md` |
| Final CTA | ปิด | ย้ำผลลัพธ์ + guarantee + ปุ่มใหญ่สุด |

## CTA copy

- ขึ้นต้นด้วยกริยา + สิ่งที่ได้: "จองรอบแรก 390 บาท" · "เลือกรอบที่สะดวก" · "ขอที่นั่งรอบนี้"
- ปุ่มเดียวกันทั้งหน้า (คำเดียวกัน) ลด cognitive load
- ใต้ปุ่มใส่ตัวลดความเสี่ยง: "ยกเลิกได้ทุกเมื่อ" · "คืนเงินถ้าไม่ปลื้ม"
- ❌ "ส่งข้อมูล" · "Submit" · "คลิกที่นี่" · "ลงทะเบียนเพื่อรับข้อมูลเพิ่มเติม"

## เช็คคุณภาพก่อนส่ง

- [ ] ลบคำว่า "ที่ดีที่สุด / ครบวงจร / มืออาชีพ / นวัตกรรม" ออกหมดแล้ว (เคลมลอยๆ)
- [ ] ทุกตัวเลขมีที่มาจริงจาก `context/`
- [ ] ไม่มีคำใน "ห้ามใช้เด็ดขาด" ของ `voice.md` หลุดมาแม้แต่คำเดียว
- [ ] อ่านออกเสียงแล้วไม่สะดุด (ประโยคยาวเกินให้ตัด)
- [ ] บนมือถือ ไม่มีย่อหน้าเกิน 3 บรรทัด
- [ ] ไม่มีเคลมสุขภาพ/การแพทย์ที่พิสูจน์ไม่ได้ (ผิดกฎหมายโฆษณา)
- [ ] ไม่มี body shaming หรือสัญญาผลลัพธ์รูปร่าง
- [ ] มีคำตอบให้ objection ทุกข้อใน `clients.md` อยู่ที่ใดที่หนึ่งในหน้า

```markdown

**Headline:**
**Sub:**
**Body / bullets:**
**CTA:** [ข้อความปุ่ม] → [ปลายทาง: #lead-form / /api/checkout]
**ภาพ:** [filename จาก manifest] · alt: [ข้อความไทย]
**ข้อมูลอ้างอิง:** [ตัวเลข/ที่มา]
```
