# Moodboard Prompt — Grid / Bento style

ใช้เมื่อผู้ใช้เลือก **B) Grid (Bento)** — เหมาะกับแบรนด์ที่ต้องการดู premium เป็นระบบ น่าเชื่อถือ
(tech, B2B, finance, clinic, high-ticket service, education)

---

## Template

คัดลอกทั้งบล็อกนี้แล้วแทนที่ทุก `[PLACEHOLDER]` — ห้ามเหลือวงเล็บเหลี่ยมในprompt สุดท้าย

```
A vertical brand moodboard for [BRAND_NAME], a [NICHE] brand that feels [BRAND_VIBE].

LAYOUT — bento grid system:
Clean modular grid of 7–10 rounded rectangular tiles of varying sizes, perfectly aligned with
consistent gutters. One large hero tile spans the full width at the top. Below it, a rhythm of
medium and small tiles: photographs, a color palette tile with labelled swatches, a typography
specimen tile, a texture tile, and one tile containing a single bold statement. Everything snaps
to the grid — the impression is order, system, control.

PHOTOGRAPHY — every photo must look like this:
[PHOTOGRAPHY_STYLE]. Lighting: [LIGHTING_MOOD]. Restrained, confident, well-composed.
Real moments over posed stock. Consistent color grading across all photographs so the tiles
feel like one family.

COLOR — [COLOR_DIRECTION]
Include one dedicated palette tile showing 5 color swatches as clean rectangles with small hex-code
style labels underneath. The rest of the board uses only those colors.

TYPOGRAPHY IN THE IMAGE:
One typography specimen tile showing the headline "[PUNCHY_HEADLINE]" in a characterful display
typeface, plus a line of smaller body text below it to show the pairing. Text must be spelled
exactly as written and be fully legible.

MATERIAL & DEPTH:
Soft realistic shadows under each tile, subtle 1px borders, very light noise texture on the
background. Tiles feel like physical cards laid on a neutral surface.

BOLD CREATIVE CHOICE: [RISK_LEVER]

OVERALL: art-directed, premium, systematic — like a page from a real brand guideline document.
Not a template. Not AI-looking. No glass morphism, no purple-pink gradients, no generic SaaS blue.
```

---

## Notes for filling it

- Bento grid lives or dies on **consistency** — state the color grading rule explicitly
- `[RISK_LEVER]` for grid style works best as one rule-breaking tile, e.g. "one tile is pure
  accent color with a single word in it", "one photograph is intentionally full-bleed and
  cropped tight"
- Good for brands that will later need a real brand guideline doc — the tiles map 1:1 to sections
- Keep the whole prompt under ~2,000 characters
